# 🧠 PokeRubApp

Aplicativo React Native que consome a [PokéAPI](https://pokeapi.co/) para exibir uma lista de Pokémon com filtro por nome, visualização de detalhes (tipo, altura, peso, habilidades), linha de evolução e gerenciamento de favoritos localmente.

---

## 🚀 Funcionalidades

- ✅ Listagem de todos os Pokémon
- 🔍 Filtro por nome
- ℹ️ Tela de detalhes com altura, peso, habilidades e tipos
- 🔁 Exibição da linha de evolução
- ⭐ Favoritar Pokémon localmente com AsyncStorage
- 📄 Tela com lista de Pokémon favoritos

---

## ⚙️ Requisitos

- Node.js (recomendado: **v18.x LTS**)
- NPM (ou Yarn)
- Git
- React Native CLI
- Android Studio (para build e emulador Android)
- JDK 17 (ou JDK 11)
- [CocoaPods (somente se usar iOS)](https://guides.cocoapods.org/using/getting-started.html)

---

## 🛠️ Configuração do ambiente

### 1. Clone o repositório

git clone https://github.com/pradovolnei/poke-rub-app.git
cd PokeRubApp

### 2. Instale as dependências

npm install
# ou
yarn install

### 3. Instale pods (iOS apenas)

npx pod-install

### 4. Execute o app

Inicie o emulador Android (ou conecte um celular).

Rode o app:
npx react-native run-android

iOS (somente no macOS)
npx react-native run-ios
